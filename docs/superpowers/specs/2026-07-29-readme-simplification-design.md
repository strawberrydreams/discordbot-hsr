# README 간소화 설계

## 목표

`README.md`는 처음 저장소를 접한 사람이 설치·설정·실행·검증을 시작하는 데 필요한 내용만 제공한다. 상시 운영자가 드물게 사용하는 상세 절차는 `docs/operations.md`로 분리해 보존한다.

## README 구성

README에는 다음만 남긴다.

1. 프로젝트 소개와 주요 기능
2. Python 3.12+, SQLite 전용이라는 요구사항
3. 가상환경·의존성·환경 파일·금지어 파일 준비
4. 최초 DB 초기화와 초기 백업
5. 테스트와 로컬 실행 명령
6. 비밀정보를 Git에 추가하지 않는다는 주의
7. launchd와 Docker를 동시에 실행하지 않는다는 주의
8. 상세 운영 문서 링크

환경변수 이름을 README에 다시 나열하지 않고 `.env.example`을 단일 카탈로그로 사용한다.

## 운영 문서 구성

`docs/operations.md`에는 기존 README의 다음 절차를 이동한다.

- macOS LaunchAgent 운영
- Docker Desktop 운영
- 백업 생성·검증·복구 테스트
- 검증된 백업으로 실제 복구
- 배포
- 코드 롤백
- 호스트 한계

명령 블록과 안전 경고는 축약하거나 삭제하지 않는다. 문서 첫머리에는 최초 설치는 README를 따르라는 링크와 launchd/Docker 동시 실행 금지 경고를 둔다.

## 범위

- `README.md`와 새 `docs/operations.md`만 변경한다.
- 코드, 환경변수 계약, 배포 파일, 백업 동작은 변경하지 않는다.
- 같은 상세 절차를 두 문서에 중복하지 않는다.

## 검증

- README에서 `docs/operations.md` 링크가 유효한지 확인한다.
- 기존 운영 섹션과 핵심 안전 경고가 운영 문서에 모두 남아 있는지 확인한다.
- Markdown heading 구조와 `git diff --check`를 확인한다.
- 문서 변경 뒤 전체 명령 테스트와 기존 콘솔 테스트를 다시 실행한다.
